UNIEXAM MAROC — VERSION DE DÉPART

Ce dossier contient un prototype statique responsive :
- index.html : accueil
- module.html : modèle de page pour chaque module
- about.html, privacy.html, contact.html : pages d'information
- styles.css : design

IMPORTANT
1. Le site n'est pas encore publié sur Internet. Il est à toi comme fichiers de départ, mais le compte d'hébergement/domaine doit être créé et contrôlé par toi.
2. Les examens affichés sont des exemples/espaces réservés : aucun vrai PDF n'est inclus.
3. Ajoute uniquement des sujets et corrigés que tu as le droit de partager.
4. Remplace les textes de confidentialité et contact par tes informations réelles avant publication.
5. Aucun emplacement publicitaire ne contient de code AdSense. Ne colle pas de code publicitaire avant d'avoir un compte approuvé et d'avoir configuré le site selon les règles Google.

TEST LOCAL
Ouvre index.html dans un navigateur. Clique sur un module pour tester sa page.

PUBLICATION GRATUITE
Tu peux publier ce site sur GitHub Pages avec un compte GitHub gratuit :
- crée un dépôt public nommé par exemple uniexam-maroc
- téléverse les fichiers du dossier à la racine du dépôt
- dans Settings > Pages, choisis Deploy from a branch, puis main et /(root)
- attends la publication et utilise l'adresse fournie par GitHub Pages

Pour modifier les noms des modules, édite les liens dans index.html. Pour ajouter un module, copie une carte module-card et change son nom dans le lien module.html?name=...
